# T-Rex Runner 🦖

A browser-based T-Rex runner game built as one of my early projects while learning JavaScript and game development.

## 🎮 About

This was one of my early experiments with building games using JavaScript and p5.js. The game is inspired by the classic endless-runner style of the Chrome Dino game.

The project is also a small snapshot of my early programming journey before starting college.

## 🕹️ How to Play

* Press **SPACE** to make the T-Rex jump.
* Avoid the obstacles.
* Try to survive for as long as possible and achieve a high score.

## 🛠️ Technologies Used

* JavaScript
* HTML
* CSS
* p5.js

## 📚 What I Learned

While working on this project, I was introduced to concepts such as:

* Game loops
* Keyboard input
* Collision detection
* Sprites and animations
* Game states
* Basic JavaScript programming
